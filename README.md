# Java Multiply Two Numbers

A simple Java program to multiply two numbers entered by the user.

## Author

**Shaik Bhanu**

## Repository Name

`shaikbhanu-java-multiply-two-numbers`

## File Name

`MultiplyTwoNumbers.java`

## Description

This program accepts two numbers from the user and calculates their product.

## Features

* Accepts two numbers from the user
* Multiplies the two numbers
* Displays the product

## Requirements

* Java JDK 8 or later

## How to Run

Compile the program:

```bash id="p0xqg8"
javac MultiplyTwoNumbers.java
```

Run the program:

```bash id="3j1m8c"
java MultiplyTwoNumbers
```

## Example

```text id="3u0kq4"
Enter first number: 10
Enter second number: 20
Product = 200
```

## Algorithm

1. Read the first number.
2. Read the second number.
3. Multiply the two numbers.
4. Store the result in the `product` variable.
5. Display the product.

## Time Complexity

**O(1)**

## Space Complexity

**O(1)**
